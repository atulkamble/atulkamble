## Professional summary

Cloud Solutions Architect, Microsoft Certified Trainer, and DevOps educator with 7+ years of experience across cloud infrastructure, Linux administration, infrastructure as code, containers, Kubernetes, CI/CD, and technical training. Founder and CEO of Cloudnautic. Delivered 100+ workshops and webinars and trained 5,000+ learners through hands-on, project-based instruction.

Experienced in designing and demonstrating secure, scalable cloud solutions; automating infrastructure and application delivery; and creating practical labs, technical content, and learning resources. Available for online training and consulting, and in-person engagements in Pune.

- **Containers and orchestration:** Docker, Kubernetes, Azure Kubernetes Service (AKS), Amazon EKS, Google Kubernetes Engine (GKE), Helm

- **Delivery approaches:** Blue-green deployment, canary releases, rolling updates, infrastructure automation

## About

I’m Atul Kamble, Founder and CEO of [Cloudnautic](https://cloudnautic.in), a Cloud Solutions Architect, and a Microsoft Certified Trainer. I work across cloud infrastructure, DevOps automation, containers, and platform engineering, and turn those practices into hands-on learning material.

I have delivered 100+ workshops and webinars and trained 5,000+ learners. My training is practical and project-led, with labs that follow the same workflow used to build, deploy, operate, and troubleshoot real systems.

- **Cloud:** AWS, Microsoft Azure, and Google Cloud
- **Infrastructure as code:** Terraform, Bicep, CloudFormation, and Ansible
- **Containers and platforms:** Docker, Kubernetes, AKS, EKS, and GKE
- **Delivery:** Azure DevOps, GitHub Actions, Jenkins, and deployment strategies
- **Operations:** Linux, monitoring, observability, security, and automation
